# lst97-oss 🌏

> Community open-source projects by [Nelson (Sio Tou Lai, lst97)](https://github.com/lst97) — Full-Stack Developer based in Melbourne, Australia 🇦🇺🇭🇰

## About

**lst97-oss** is the home for community-facing open source built by [@lst97](https://github.com/lst97).
The focus is practical, boring-in-a-good-way tooling: real-time community services, Cantonese language tools,
developer utilities, and minimal full-stack templates — built in the open, free for everyone.

- 👨‍💻 Maintainer: **Nelson** — Full-Stack Developer ([lst97.dev](https://www.lst97.dev))
- 🌱 Current stack: **TypeScript · React · TanStack Start · Bun · PostgreSQL · Payload CMS**
- 📫 Reach out: **laisiotou1997@gmail.com** · [lst97.dev](https://www.lst97.dev)
- 💼 Open to collaborations and community contributions

## Repositories

| Project | What it is |
|---|---|
| [last-cli](https://github.com/lst97-oss/last-cli) | Interactive CLI for creating LAST projects — Payload + TanStack Start, or blank TanStack Start |
| [last-payload-tanstack-start-template](https://github.com/lst97-oss/last-payload-tanstack-start-template) | Bare Payload v4 + TanStack Start (RSC, Nitro) template on Bun — minimal boot for `/admin` and `/api` |
| [last-tanstack-start-template](https://github.com/lst97-oss/last-tanstack-start-template) | Blank TanStack Start template (no CMS) — owns the canonical business-backend kernel shared with the Payload template |
| [last-lst97-dev](https://github.com/lst97-oss/last-lst97-dev) | Personal portfolio plus chat assistance with RAG and Jev |
| [last-comments](https://github.com/lst97-oss/last-comments) | Self-hosted comment threads for any page — Payload CMS, TanStack Start, Bun/Postgres, moderation, publisher API keys and plugins |
| [last-comments-widgets](https://github.com/lst97-oss/last-comments-widgets) | Drop-in comment widgets for a last-comments server — React, Vue, Angular and plain HTML on one shared API client and theme |

More community projects live under [@lst97](https://github.com/lst97?tab=repositories) and are migrating here over time, including:

- 🏸 **smartplay-hk-oss** — fast, minimal open alternative for HK LCSD facility availability
- 🗣️ **CantoCap** — accurate Cantonese subtitles from audio/video (Whisper + LLM)
- 📝 **CantoLyr** — Cantonese lyrics processing and conversion utilities
- 🗑️ **bin-time-crawler** — bin collection schedules for Australian councils
- 📡 **info-hawker-server** — unified Australian open-data API
- 📍 **gnaf-autocomplete** — self-hosted Australian address autocomplete (16M addresses, G-NAF)
- 🛠️ **claude-code-sub-agents** — specialized AI subagents for full-stack workflows
